# P2 – Reservefragen Tastenkombinationen

**Bereich:** Tastenkombinationen A1–A7  
**Zweck:** Reserve-/Alternativfragen zu P1

---

## A. Szenarioreserve – 4 P

Wähle jeweils die **sinnvollste Tastenkombination**.

### 1.
Mia schreibt im Unterricht einen Bericht. Sie möchte einen markierten Absatz kopieren, damit sie ihn an einer zweiten Stelle nochmals verwenden kann.

- ☐ Ctrl + C
- ☐ Ctrl + V
- ☐ Ctrl + X

### 2.
Noah erstellt im Büro eine Präsentation. Er möchte einen markierten Satz an der aktuellen Stelle entfernen und später an einer anderen Stelle einfügen.

- ☐ Ctrl + X
- ☐ Ctrl + C
- ☐ Ctrl + Z

### 3.
Lea hat eine Adresse aus einer E-Mail kopiert. Sie möchte sie in ein Formular einfügen.

- ☐ Ctrl + V
- ☐ Ctrl + C
- ☐ Ctrl + F

### 4.
Sara löscht in ihrem Schulprojekt versehentlich einen Absatz. Sie möchte den letzten Schritt sofort rückgängig machen.

- ☐ Ctrl + Z
- ☐ Ctrl + Y
- ☐ Ctrl + X

## B. Aus P1 verschobene Reservefragen – 8 P

Diese Fragen bleiben als Alternativen erhalten, obwohl ihre Inhalte im aktuellen P1 teilweise bereits in Transfer-, Bonus- oder Vergleichsaufgaben vorkommen.

1. **Ctrl + S** – Welche Aussage beschreibt die Funktion korrekt?
   - ☐ Speichert das aktuelle Dokument.
   - ☐ Öffnet die Suche.
   - ☐ Kopiert markierte Inhalte.

2. **Ctrl + F** – Welche Aussage beschreibt die Funktion korrekt?
   - ☐ Sucht nach einem Begriff im aktuellen Dokument oder auf der Webseite.
   - ☐ Fügt Inhalte ein.
   - ☐ Springt ans Dokumentende.

3. Du hast einen Browser-Tab versehentlich geschlossen und möchtest ihn zurückholen.  
   **Ctrl + Shift + T / Ctrl + T / Ctrl + Shift + N**

4. Du möchtest zum nächsten geöffneten Browser-Tab wechseln.  
   **Ctrl + Tab / Alt + Tab / Ctrl + T**

5. Du möchtest zum vorherigen Browser-Tab wechseln.  
   **Ctrl + Shift + Tab / Ctrl + Tab / Ctrl + Shift + T**
