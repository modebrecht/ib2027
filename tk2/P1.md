# P1 – Übungstest Tastenkombinationen

**Bereich:** Tastenkombinationen A1–A7  
**Zeit:** ca. 35–40 Minuten  
**Punkte:** 41 + max. 2 Bonuspunkte  
**Hilfsmittel:** keine Kursseiten oder Merkblätter öffnen

---

## 1. Was macht dieses Tastenkürzel? – 4 P

Kreuze jeweils die **richtige Aussage** an.

### 1. Ctrl + C
- ☐ Kopiert markierte Inhalte.
- ☐ Fügt kopierte Inhalte ein.
- ☐ Schliesst die aktuelle Anwendung.

### 2. Ctrl + V
- ☐ Speichert das Dokument.
- ☐ Fügt kopierte oder ausgeschnittene Inhalte ein.
- ☐ Macht den letzten Schritt rückgängig.

### 3. Ctrl + X
- ☐ Schneidet markierte Inhalte aus.
- ☐ Sucht nach einem Begriff.
- ☐ Öffnet eine Datei.

### 4. Ctrl + Z
- ☐ Macht den letzten Schritt rückgängig.
- ☐ Markiert alles.
- ☐ Druckt das Dokument.

**Je 1 P**

## Bonus – max. +2 P

Die Bonusfragen verbinden mehrere ähnliche Tastenkombinationen und verlangen genaues Unterscheiden.

### Bonus 1 – Im Browser bleiben (+1 P)

Du hast mehrere Browser-Tabs geöffnet und gleichzeitig Word. Du möchtest zum **vorherigen Browser-Tab** wechseln, ohne zu Word zu wechseln. Welche Tastenkombination verwendest du?

### Bonus 2 – Fenster neu anordnen (+1 P)

Ein Fenster ist maximiert. Du möchtest es zuerst wieder auf normale Grösse bringen und danach **links** am Bildschirm andocken. Nenne die **zwei Tastenkombinationen in der richtigen Reihenfolge**.

> Bonuspunkte zählen zusätzlich zu den 41 regulären Punkten. Maximalnote: 6.0.

# Lösungen / Erwartungshorizont

## 1. Was macht dieses Tastenkürzel?

1. **Ctrl + C:** Kopiert markierte Inhalte.
2. **Ctrl + V:** Fügt kopierte oder ausgeschnittene Inhalte ein.
3. **Ctrl + X:** Schneidet markierte Inhalte aus.
4. **Ctrl + Z:** Macht den letzten Schritt rückgängig.

## 2. Tastenkombinationen im Alltag

1. **Ctrl + S**
2. **Ctrl + A**
3. **Ctrl + F**
4. **Ctrl + End**
5. **Ctrl + Shift + V**
6. **Ctrl + Y**

## 3. Sonderzeichen mit AltGr

1. `@` → **AltGr + 2**
2. `#` → **AltGr + 3**
3. `€` → **AltGr + E**
4. `|` → **AltGr + 7**
5. `\` → **AltGr + <**
6. `[` → **AltGr + ü**
7. `{` → **AltGr + ä**
8. `°` → **AltGr + 4**

## 4. Programme & Browser

1. **Ctrl + N**
2. **Ctrl + T**
3. **F5**
4. **Ctrl + L**

## 5. Windows & Arbeitsalltag

1. **Win + D**
2. **Win + E**
3. **Win + Shift + S**
4. **Ctrl + Shift + Esc**
5. **Win + V**

## 6. Kurz erklären

Sinngemäss korrekt; Stichwort oder Satz genügt:

1. **Ctrl + H in Word:** Öffnet Suchen und Ersetzen.
2. **Ctrl + P:** Öffnet den Druckdialog.
3. **Ctrl + O:** Öffnet den Dialog zum Öffnen einer Datei.
4. **Win + ←:** Dockt das aktive Fenster links am Bildschirm an.
5. **Win + ↑:** Maximiert das aktive Fenster.
6. **Win + ↓ bei maximiertem Fenster:** Verkleinert das Fenster bzw. stellt die normale Fenstergrösse wieder her.

## 7. Nicht verwechseln

### A) Ctrl + Tab und Alt + Tab

- **Ctrl + Tab:** zwischen Tabs innerhalb eines Programms bzw. Browsers wechseln.
- **Alt + Tab:** zwischen geöffneten Programmen/Fenstern wechseln.

**Je sinnvoll erklärter Unterschied 1 P.**

### B) Ctrl + W und Alt + F4

- **Ctrl + W:** typischerweise aktuellen Tab bzw. aktuelles Dokument schliessen.
- **Alt + F4:** aktives Fenster bzw. Programm schliessen.

**Je sinnvoll erklärter Unterschied 1 P.**

## 8. Transfer

### A) Zwei Programme nebeneinander

**Win + →.** Damit wird das aktive Browserfenster rechts angedockt und auf der anderen Bildschirmhälfte bleibt Platz für PowerPoint.

- richtige Tastenkombination: **1 P**
- sinnvolle Begründung: **1 P**

### B) Platz kurz verlassen

**Win + L.** Der Computer wird gesperrt, während die geöffneten Programme und Dokumente erhalten bleiben.

- richtige Tastenkombination: **1 P**
- sinnvolle Begründung: **1 P**
